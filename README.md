# Vehicle Service Booking and Cost Estimation System

A web-based application designed to streamline vehicle service reservations and provide users with instant cost estimates for their automotive maintenance needs.

## 🚀 Features
* **Service Booking:** Users can easily schedule maintenance or repair appointments through a clean interface.
* **Cost Estimation:** Dynamic, client-side calculation of service costs before confirming a booking.
* **Responsive UI:** An interactive frontend built to work seamlessly across devices.
* **Backend Processing:** Secure form submission and booking logic handled via PHP.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP

## 📂 Project Structure
* `index.html` - The main landing page.
* `service.html` - The service selection and booking interface.
* `style.css` - Custom styling and layout for the application.
* `script.js` - Client-side interactivity and cost estimation logic.
* `process_service.php` - Server-side script to handle and process booking submissions.
